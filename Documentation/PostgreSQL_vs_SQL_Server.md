# PostgreSQL vs SQL Server

## Overview

As a SQL Server DBA, I am learning PostgreSQL by comparing equivalent concepts between the two platforms.

| SQL Server | PostgreSQL |
|------------|------------|
| SSMS | pgAdmin |
| sa | postgres |
| Transaction Log | WAL |
| SQL Agent | pg_cron / OS Scheduler |
| Login | Role |
| Database | Database |
| Schema | Schema |
